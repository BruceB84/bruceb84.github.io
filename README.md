# Portfolio de Bruce Bouisson

Site statique : `index.html` + `photo.jpg`. Aucune installation nécessaire.

## Mise en ligne sur GitHub Pages

1. Crée un compte sur github.com si tu n'en as pas.
2. Crée un nouveau dépôt **public** nommé exactement `TON-PSEUDO.github.io`
   (remplace TON-PSEUDO par ton nom d'utilisateur GitHub).
3. Dans le dépôt : **Add file > Upload files**, glisse `index.html`, `photo.jpg`
   et ce `README.md`, puis **Commit changes**.
4. Va dans **Settings > Pages** : Source = *Deploy from a branch*,
   Branch = `main`, dossier `/ (root)`, puis **Save**.
5. Après une à deux minutes, le site est en ligne sur
   `https://TON-PSEUDO.github.io`.

## Modifier le site

Ouvre `index.html` dans GitHub (icône crayon), modifie le texte, puis
**Commit changes**. La mise à jour est en ligne en une minute environ.

Pour changer la photo, remplace `photo.jpg` par une image carrée du même nom.
